# Pass11 Packaging Policy

Quick package keeps the parallel workbench and query surfaces for fast inspection.
Full materialized package keeps the base outputs/runtime store for data traceability while remaining below the 100MB target where possible.

Removed/avoided: duplicate historical artifact archives and redundant old pass reports.
Retained: latest Pass10 implementation coverage audit, upper-layer empirical analysis, Pass11 parallel workbench, quick/full run scripts.
