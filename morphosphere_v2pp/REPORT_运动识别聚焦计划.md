# 聚焦计划：运动状态区分
# 2026-05-09

---

## 目标

让系统能够可靠地区分不同的运动状态，并且这个能力是可验证的、
不是自欺欺人的。

---

## 当前实际状况

| 已有 | 问题 |
|------|------|
| 6种运动体制生成器 | 运动模式是自己定义的，不是从数据中发现的 |
| 基础分类器 71% | 靠规则，不靠学习 |
| 增强分类器+记忆 100% | 在同一个数据上训练和测试，结果不可信 |
| Hebbian记忆 | 本质是查找表，不是真正的学习 |

---

## 计划：三步走

### 第一步：让评估变诚实（1-2天）

这一步不写任何新功能，只修复评估方法。

做什么：
  1. 用不同的随机种子生成训练集和测试集
     - 训练: seed = 42, 100, 200 (3组 × 60窗口)
     - 测试: seed = 500, 600, 700 (3组 × 60窗口，完全独立)
  2. 在训练集上积累Hebbian记忆
  3. 在测试集上只评估，不学习
  4. 报告: 均值 ± 标准差，混淆矩阵

为什么先做这一步：
  如果在独立测试集上准确率掉到50%，说明当前的"100%"是假的。
  如果仍然80%+，说明系统确实学到了可迁移的东西。
  这一步的结果决定后面的方向。

验收：测试集准确率 ± 标准差，混淆矩阵

---

### 第二步：让学习变真实（3-5天）

根据第一步的结果，改进学习机制。

当前问题：
  Hebbian记忆是离散化的查找表。
  特征被四舍五入到 (0.2, 0.8, 0.1, 0.0, 0.3, 0.9)，
  然后存一个字符串→体制的映射。
  这不是学习，这是背答案。

替换方案：用真正的在线学习

方案A：在线贝叶斯更新（推荐，最简单）
  对每种运动体制，维护一个特征分布的均值和方差：
    μ_k = 运动体制k的特征均值向量
    Σ_k = 运动体制k的特征协方差矩阵
    n_k = 该体制被观测到的次数

  每次看到新数据：
    n_k += 1
    μ_k ← μ_k + (1/n_k) · (feature - μ_k)     # 在线均值更新
    Σ_k ← Σ_k + (n_k-1)/n_k · (feature - μ_k)² # 在线方差更新

  分类时用贝叶斯后验：
    p(regime=k | feature) ∝ π_k · N(feature | μ_k, Σ_k)

  这是数学上严格的，不是查找表。

方案B：简单神经网络（更强但更复杂）
  一个2层的感知器，输入6维特征，输出6类概率。
  用在线SGD训练。
  需要 numpy 实现，不需要 PyTorch。

建议：先做方案A。如果不够再加方案B。

需要改的代码：
  - motion_recognition_engine.py 中的 MotionStateRecognizer
  - classify() 方法：从规则判断 → 贝叶斯后验
  - learn() 方法：从查找表写入 → 在线均值/方差更新
  - 大约 80 行代码

不需要改的：
  - pipeline_engine.py — 完全不动
  - source_adapters.py — 完全不动
  - 所有数据库表 — 完全不动
  - 只动 motion_recognition_engine.py 这一个文件

验收：
  - 独立测试集上准确率 > 80%
  - 不再有查找表（Hebbian记忆变成参数分布）
  - 新运动体制（训练时没见过的seed）也能正确分类

---

### 第三步：让运动更丰富（3-5天）

当前6种运动体制是手动定义的固定模式。
真实的细胞运动远比这复杂。

扩展方向：

1. 增加运动体制数量（从6种到12种）：
   - 旋转运动 (rotation)
   - 收缩运动 (contraction)
   - 扩张运动 (expansion)
   - 趋化运动 (chemotaxis) — 朝一个方向聚集
   - 混合运动 — 一部分细胞静止，一部分漂移
   - 渐变运动 — 从慢漂移平滑过渡到快漂移

2. 增加运动的连续性（从离散体制到连续参数空间）：
   当前：每个窗口有一个标签（stationary/drift/...）
   改为：每个窗口有一组连续参数（速度、方向、周期、噪声）
   分类器的目标变成：估计这些连续参数

3. 接入真实运动数据（可选但有价值）：
   Allen Brain的钙成像数据包含真实的细胞位置信息。
   可以提取真实的细胞运动轨迹，看系统能否区分
   不同皮层区域或不同刺激条件下的运动模式差异。

验收：
  - 12种运动体制的分类准确率 > 75%
  - 或：连续参数估计的均方误差 < 0.1
  - 或：能在真实数据上发现有意义的运动模式差异

## 时间线

```
第1-2天: 独立测试集评估 → 得到真实基线准确率
第3-5天: 在线贝叶斯分类器 → 替换查找表
第6-7天: 扩展运动体制 → 更丰富的测试
```

总计约1周。如果结果好，可以继续接真实数据。
如果结果不好，说明需要先回去改底层特征提取。
