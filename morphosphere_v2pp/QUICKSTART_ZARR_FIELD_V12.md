# Quickstart: Zarr/HDF5 Field Runtime Adapter v1.2

Run from package root:

```bash
./run_local_zarr_field_v12.sh
```

Primary database:

```text
outputs/morphosphere_zarr_field_v12_output_database.db
```

Active chunked field store:

```text
runtime_store/v12/field_store_v12.zarr
```

HDF5 is represented by contract only:

```text
runtime_store/v12/hdf5_field_store_contract_v12.json
```
