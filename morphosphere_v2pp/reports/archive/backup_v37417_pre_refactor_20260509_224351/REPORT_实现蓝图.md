## 一、真实数据

### 1.1 数据源：Allen Brain Observatory

Allen Brain Observatory 是公开的、免费的、大规模钙成像数据集。

| 属性 | 值 |
|------|-----|
| 数据类型 | 双光子钙成像 (two-photon calcium imaging) |
| 记录对象 | 小鼠视觉皮层 ~25,000 个神经元 |
| 格式 | NWB (Neurodata Without Borders)，基于 HDF5 |
| 包含 | ΔF/F 荧光轨迹、细胞坐标 (x,y)、刺激信息 |
| 大小 | 每个session约 1-5 GB |
| API | Python AllenSDK |

### 1.2 具体接入方案

```
安装：pip install allensdk

代码路径：
  1. BrainObservatoryCache 获取 session 列表
  2. 按皮层区域 (VISp, VISl 等) 和 Cre-line 过滤
  3. get_ophys_experiment_data(experiment_id) 下载
  4. 提取:
     - dff_traces: (n_cells × n_timepoints) 的 ΔF/F 矩阵
     - cell_specimen_ids: 细胞ID
     - roi_masks: 细胞空间位置 (x, y 坐标)
     - stimulus_table: 视觉刺激的时间和类型
```

### 1.3 与现有系统的对接

需要写一个新的 adapter：

```
class AllenBrainAdapter:
    """从 Allen Brain NWB 文件读取真实钙成像数据。"""

    def generate_cells(self, window_k):
        """
        不再用 random.gauss 生成位置，而是：
        - x, y: 从 roi_masks 提取的真实细胞坐标
        - z: 0 (二维平面)
```

## 二、严格变分数学

### 2.1 当前问题

当前 PRX 分解是：
  score = λ₁·RLIS + λ₂·CM + λ₃·FHPMS + λ₄·BM
  ρ = softmax(score)

这不是变分法。变分法需要：
  (1) 定义一个目标泛函 J[ρ]
  (2) 在满足约束的分布空间中，找到使 J[ρ] 取极值的 ρ*
  (3) 证明（或数值验证）ρ* 是唯一的或局部最优的

### 2.2 实现方案：变分EM

变分EM的核心思想：

```
观测数据 X = {所有窗口的细胞位置和信号}
隐变量 Z = {每个细胞属于 P/R/X 的分配}
参数 θ = {P/R/X 各类别的分布参数}

目标：最大化 ELBO = E_q[log p(X,Z|θ)] - E_q[log q(Z)]

E步：固定 θ，更新 q(Z) ← 使 KL[q(Z) || p(Z|X,θ)] 最小
M步：固定 q(Z)，更新 θ ← 使 ELBO 最大
```

### 2.3 具体数学

P/R/X 分解建模为一个混合模型：

```
p(cell_i | z_i = P) = N(μ_P, Σ_P)    # P类细胞的信号分布
p(cell_i | z_i = R) = N(μ_R, Σ_R)    # R类细胞的信号分布  
p(cell_i | z_i = X) = N(μ_X, Σ_X)    # X类细胞的信号分布
p(z_i = k) = π_k                      # 先验概率

E步：
  γ_ik = p(z_i=k | cell_i, θ)         # 后验责任 (responsibility)
       = π_k · N(cell_i | μ_k, Σ_k) / Σ_j [π_j · N(cell_i | μ_j, Σ_j)]

M步：
  π_k = Σ_i γ_ik / N                  # 更新先验
  μ_k = Σ_i γ_ik · cell_i / Σ_i γ_ik # 更新均值
  Σ_k = Σ_i γ_ik · (cell_i - μ_k)(cell_i - μ_k)^T / Σ_i γ_ik  # 更新协方差

ELBO = Σ_i Σ_k γ_ik · [log π_k + log N(cell_i|μ_k,Σ_k) - log γ_ik]
```

### 2.4 将 PRX 7 分量融入变分框架

当前的 7 分量可以成为先验的结构化约束：

```
不再是 3 类 (P/R/X) 的简单混合模型，而是 7 类：
  p_core, p_band, r_core, r_band, m_band, x_true, u

每一类的先验 π_k 不是自由参数，而是受四源 (RLIS, CM, FHPMS, BM) 约束：
  log π_k ∝ λ_L·f_L(k) + λ_C·f_C(k) + λ_H·f_H(k) + λ_B·f_B(k)

这样四源融合不再是输出，而是先验的超参数。
ELBO 最大化会自动找到最优的后验分配。
```

### 2.5 技术路径选择

| 方案 | 难度 | 严格性 | 推荐 |
|------|------|--------|------|
| 手写 numpy EM | 中等 | 充分 | 初阶推荐 |
| PyMC + ADVI | 较高 | 高 | 中阶推荐 |
| Pyro + SVI | 高 | 最高 | 如需GPU加速 |

建议先用 numpy 实现基本的 EM，验证可行后再考虑 PyMC。

### 2.6 工作量

| 任务 | 预估时间 |
|------|---------|
| 实现 7 类 EM (numpy) | 2-3 天 |
| ELBO 计算和收敛监控 | 1 天 |
| 替换 pipeline_engine 中的 softmax 为 EM | 1-2 天 |
| 验证 ELBO 确实单调递增 | 1 天 |
| **总计** | **5-7 天** |

### 2.7 验收标准

- ELBO 在每轮 EM 迭代中单调递增（或在数值误差内不降）
- 后验 γ_ik 给出每个细胞属于 7 类中每一类的概率
- 收敛后的分配应比当前 softmax 结果更稳定、更具可解释性

## 三、独立测试集

### 3.1 当前问题

当前所有实验都在同一个数据生成器上进行。
seed=42 生成训练数据，seed=42 又生成测试数据 → 数据泄露。

### 3.2 实现方案

```
方案 A：合成数据的严格分离（如果暂不接真实数据）

  训练集: seed=42, 100, 200    (3组 × 60窗口 = 180 窗口)
  验证集: seed=300, 400         (2组 × 60窗口 = 120 窗口)
  测试集: seed=500, 600, 700    (3组 × 60窗口 = 180 窗口)

  规则：
  - 训练集上学习 Hebbian 记忆和分类参数
  - 验证集上调超参数 (λ权重, 阈值等)
  - 测试集上只跑一次，报告最终准确率
  - 绝不在测试集上修改任何参数


方案 B：真实数据的标准分离（接入 Allen Brain 后）

  训练集: session 1-5   (5个不同的实验session)
  验证集: session 6-7   (2个session)
  测试集: session 8-10  (3个session，不同小鼠)

  更严格：
  - 测试集的小鼠与训练集不同 → 测试跨个体泛化能力
  - 测试集的皮层区域与训练集不同 → 测试跨区域泛化
```

### 3.3 统计检验

报告结果时必须包含：

```
  - 均值 ± 标准差 (多次运行)
  - 95% 置信区间
  - 与随机基线的显著性检验 (p-value)
  - 混淆矩阵 + 精确率/召回率/F1
```

### 3.4 工作量

| 任务 | 预估时间 |
|------|---------|
| 重构 runner 支持 train/val/test 分离 | 1 天 |
| 实现 k-fold 交叉验证 | 1 天 |
| 添加统计检验 (scipy.stats) | 半天 |
| **总计** | **2-3 天** |

### 3.5 验收标准

- 训练集和测试集的 seed 完全不同
- 报告的准确率附带 95% 置信区间
- 训练/测试准确率差距 < 15% (否则过拟合)

## 四、非平凡收敛

### 4.1 当前问题

当前5轮分析，每轮读同一份数据 → drift=0。
这不是收敛，是重复。

### 4.2 什么是真正的非平凡收敛

```
真正的收敛需要：

第1轮：用初始参数分析数据 → 得到 PRX 分配 ρ₁
       根据 ρ₁ 更新 Hebbian 权重 w₁
第2轮：用新的 w₁ 重新分析 → 得到 ρ₂ (应该与 ρ₁ 不同)
       根据 ρ₂ 更新 w₂
第3轮：用 w₂ 再分析 → 得到 ρ₃
       ...
第N轮：‖ρₙ - ρₙ₋₁‖ < ε → 收敛

关键：每轮的分析结果必须影响下一轮的输入。
     否则就不存在"迭代"，只存在"重复"。
```

### 4.3 实现方案

需要修改 run_multiround_convergence()，加入"反馈环路"：

```
反馈1：Hebbian权重更新
  每轮结束后，根据当前 PRX 分配更新 Hebbian 权重：
  w_ij ← w_ij + η · γ_i(P) · γ_j(P)  (两个P类细胞的关联加强)
  w_ij ← w_ij - δ · γ_i(P) · γ_j(R)  (P和R混在一起的关联削弱)
  → 下一轮的 FHPMS 视角评分会不同

反馈2：先验更新
  每轮结束后，用当前 γ_ik 的均值更新先验 π_k：
  π_k^(t+1) = (1-α)·π_k^(t) + α·(1/N)·Σ_i γ_ik^(t)
  → 下一轮的 E 步起点不同

反馈3：传输阈值自适应
  如果当前轮有大量细胞被分配到 u (未解析)，降低传输阈值：
  threshold^(t+1) = threshold^(t) · (1 + β·u_ratio)
  → 下一轮会接受更多传输边，提供更多信息
```

### 4.4 收敛性保证

为了确保收敛（而不是振荡）：

```
  1. 学习率衰减: η^(t) = η₀ / (1 + t/τ)
  2. 动量平滑: ρ_smooth = (1-m)·ρ_current + m·ρ_previous
  3. 收敛条件: ‖ρₙ - ρₙ₋₁‖₂ < ε 且 连续 3 轮满足
  4. 最大轮次: 上限 20 轮，防止无限迭代
  5. ELBO 监控: 如果 ELBO 下降，回退到上一轮参数
```

### 4.5 工作量

| 任务 | 预估时间 |
|------|---------|
| 实现 Hebbian 反馈环路 | 1-2 天 |
| 实现先验更新和阈值自适应 | 1 天 |
| 实现收敛检测和安全机制 | 1 天 |
| 验证 ELBO 单调性 | 1 天 |
| 观测和分析收敛轨迹 | 1 天 |
| **总计** | **5-6 天** |

### 4.5 验收标准

- drift > 0 (至少前几轮应该有非零漂移)
- drift 最终趋向 0 (收敛到不动点)
- 收敛后的 PRX 分配比初始分配更"锐利"(熵更低)
- ELBO 单调递增
