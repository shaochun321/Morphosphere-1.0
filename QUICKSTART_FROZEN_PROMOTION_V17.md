# Quickstart v1.7

Run:

```bash
python3 -S morphosphere_v2pp/scripts/run_frozen_promotion_acceptance_v17.py outputs/morphosphere_frozen_promotion_v17_output_database.db
```

The candidate profile is staged at:

```text
morphosphere_v2pp/configs/frozen_calibration_profile_v17_candidate.json
```

It is not applied automatically.
