## Mainline claim

The project mainline is not RMI, deployment, packaging, or release gates. The mainline is:

```text
source information point
-> 3D/4D backprojection
-> trajectory/T window
-> O/support candidate
-> P/R/Xin role split
-> counter-evidence/masking
-> external entropy ledger governance
-> attention path
-> hyperedge incidence
-> variational path/Xin_var
-> Xin carrier/external readout
-> process_window query surface
```

## What changes information state

The following modules are counted as information-state changing layers:

- trajectory/T window: point stream becomes process material.
- T/O/P/R/Xin: process material becomes stable support / counter-pressure / residual roles.
- counter-evidence/masking: pressure is routed into R-chain, masked/noise, or Xin residual.
- attention path: P/R/Xin/anomaly/boredom changes resource priority.
- hyperedge incidence: role/ledger/proxy participants become high-order co-participation events.
- variational path/Xin_var: local roles become path-level closure/defect proxies.

The following are not mainline state changes by themselves:

- RMI H2/H3: query index.
- native anchor fact: evidence hardening.
- safe stress guard: runtime guard.
- semantic quarantine: boundary sidecar.
- quick/complete packages: delivery tools.
