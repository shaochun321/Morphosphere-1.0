# Morphosphere v1.6 Quickstart

This layer adds Sensor Fusion Memory + Drift Calibration on top of v1.5 multi-rate clock sync.

Run:

```bash
cd morphosphere_sensor_fusion_memory_v16_package
./run_local_sensor_fusion_memory_v16.sh
```

Boundary: v1.6 only stages calibration recommendations. It does not hot-swap parameters, rewrite source facts, or let Xi replace P/R.
