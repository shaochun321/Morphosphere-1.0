# m short-root package

This is the short-folder v2.7R package. Extract packages into the same directory; the project root will be `m/`.

Run:

```bash
cd m
python3 bin/check.py
python3 bin/status.py
```

Compatibility scripts also exist at:

```bash
python3 morphosphere_v2pp/scripts/run_source_lineage_acceptance_v27r.py
python3 morphosphere_v2pp/scripts/lineage_status_v27r.py
```
